Demand Forecasting & Inventory Optimization

Problem:
FMCG supply chains require accurate demand forecasting to balance inventory costs and service levels.

Approach:
i) Built a time-series forecasting model using lag features (1, 7, 30 days)
ii) Trained a machine learning model to predict daily demand
iii) Evaluated performance using MAE (~6.5)

Key Features
i) Time-based feature engineering
ii) Lag-based forecasting
iii) Demand variability analysis

Business Impact
i) Identified high-risk products based on demand variability
ii) Suggested dynamic safety stock adjustments
iii) Improved inventory planning decisions
